# Portfolio — Cédric Jaupitre

Static website (no build step). Open `index.html` in a browser to preview.

| File | What it is |
| --- | --- |
| `index.html` | Page structure and styles |
| `assets/content.js` | All texts, in English / 日本語 / Français |
| `assets/photos.js` | Photo galleries (experiences and commitments) |
| `assets/scenes.js` | Animated backgrounds |
| `assets/app.js` | Globe, languages, interactions |
| `assets/game.js` | Closing mini-game |
| `assets/photos/`, `assets/logos/` | Images |
| `assets/docs/` | Reference letters (PDF) |
| `cv-cedric-jaupitre.pdf` | CV linked from "Download CV" |

The site opens in the visitor's browser language (French, Japanese, otherwise English).
Direct links: `?lang=ja`, `?lang=fr`, `?lang=en`.
